## What Was Implemented

Workout and plan sections now count from the first actual row. The first eight rows enter 40 ms apart, starting immediately. Ordinary navigation shows content immediately alongside the existing route animation. When a visible Suspense loading screen resolves on the same route, its visual copy fades out and the new content fades in. Guard and onboarding placeholders use their ordinary lifecycle.

Coach AI identifies the message IDs created by the athlete’s send or retry action. Each new bubble fades in from 95% scale at the sender’s lower corner. Regenerating an answer animates only the replacement answer. Stored messages appear at full opacity, including when history arrives after mount. Reduced motion keeps the fade.

The cold-start overlay still reveals the app over 900 ms. The shell fades, while the sign-in panel and page-title surface can scale without moving viewport-fixed controls. Buttons retain their color fades while pressed and on release. Inline links can wrap within prose. The spring feature check now tests the transition property that consumes the curve.
