## Original Goal
Make Coach AI text stream evenly through bursts, block finalization and completion while retaining existing controls. This is fix round 1 of 3, restricted to the seven findings Troy supplied from /checkit attempt 1 at be8e222.

## What Was Implemented
Reveal pacing now measures characters arriving between chunks, holds that estimate through gaps and gradually approaches it with a 250 ms smoothing time constant. A bounded 25% backlog correction prevents the rate from falling behind a sustained fast reply. The old 240 characters/second ceiling is removed. At completion the pending text sets a steady drain target of at least backlog / 1.2 seconds, approached over 80 ms; it does not slow down as the last characters disappear. Tests finish 1,500 through 1,000,000 pending characters within 1.5 seconds at 30, 60 and 120 Hz. A fresh 1,500-character browser hook probe finished 1,489 pending characters in 1,253.4 ms, with a maximum 13-character step.

The fixed eight-character limit could not satisfy the new arbitrary-length drain requirement. The per-frame cap is now max(8, ceil(received length / 30)), a reply-relative hard bound. Typical actual drain steps are much smaller: 1,500 pending characters produce at most 21 characters/frame at 60 Hz in the pure simulation. The first response still starts from zero; completed-on-mount replies, reduced motion and delayed opacity-only Take-card display are retained.

The caret has a positioned fallback for an empty live tail, a table or a rule. It stays visible between chunks after a blank line without changing existing block geometry. The follow controller checks position on mount, so a long thread opened away from the bottom stays there. Every pause sets the same state that reveals Latest, including short upward scrolls. Upward movement is compared against the prior position clamped to the current document bottom, so height shrink from a shorter Take card does not register as user scrolling. Assistant messages report drain transitions through a stable callback; Latest is available only during a stream or active drain, then disappears when idle. Error messages set a failure flag that cancels the reveal loop and clears the drain state.

All seven queued fixes are implemented. Browser regression probes used the actual edited components in an isolated harness, without an authenticated account or the API stream. They are supplementary evidence; the real-flow criteria stay partial.
