## Decisions Already Made

- Decision: Stack is Cloudflare D1 + Auth.js (NextAuth v5) with `@auth/d1-adapter`; runtime bindings via `@opennextjs/cloudflare`. Reason: Troy's explicit instruction for this project — Supabase is excluded here even though it is the default elsewhere.
- Decision: Session strategy is `jwt` with the D1 adapter still persisting `users` + `accounts`. Reason: the request gate (`src/proxy.ts`) must verify sessions without a D1 round trip on every navigation; JWT needs only `AUTH_SECRET`. The adapter still writes `users`/`accounts` on sign-in, so the D1 user row requirement holds. Document this choice (and the fact that the `sessions` table exists but is unused) in the debrief.
- Decision: Sign-in route is `/sign-in` (outside the `(app)` group, public). Sign-out control lives on `/profile`. Reason: keeps the `(app)` layout and `PlanGuard` untouched; `/profile` is the only settings-like surface today.
- Decision: The request gate is server-side (`src/proxy.ts`, Next 16 naming) and redirects with `callbackUrl`. Reason: no client-side flash of app content for logged-out users; the existing client guards remain as a second layer, not the gate.
- Decision: Apple `clientSecret` is derived at runtime from `APPLE_TEAM_ID` / `APPLE_KEY_ID` / `APPLE_PRIVATE_KEY` / `AUTH_APPLE_ID` when `AUTH_APPLE_SECRET` is not provided. Reason: Apple secrets expire every 6 months; deriving them avoids a manual rotation chore and gives us unit-testable business logic.
- Decision: The native iOS bundle talks to the hosted auth origin through `NEXT_PUBLIC_AUTH_ORIGIN` (never same-origin `/api/auth`). Reason: `build:ios` is a static export with `src/app/api` stripped — there is no auth server inside the bundle.
- Decision: Static export excludes `src/proxy.ts`. Reason: Next.js rejects `output: "export"` when a proxy/middleware file exists; route gating inside the iOS bundle is client-side against the hosted session endpoint.
- Decision: Local verification uses `--local` miniflare D1 and a locally generated `AUTH_SECRET` (`npx auth secret` -> `.env.local`, never committed). Reason: neither needs a Cloudflare login or Troy's credentials.
- Decision: Vitest is added as a dev dependency. Reason: project rule — new business logic (Apple secret builder, route matcher) requires unit tests; there is no unit test runner today.
