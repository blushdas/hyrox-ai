## Original Goal
Populate the open and pro HYROX programs from the checked-in source documents, select the appropriate program by profile category, and make workout cards open populated detail pages while preserving beginner content.

## What Was Implemented
Open and pro each now provide 60 sessions across 12 weeks. Their source workout and coaching bullets feed the existing session templates and parser. Category selection chooses the corresponding generator, with an explicit beginner fallback for doubles and unknown values. Workout cards now navigate to /session/[id]. The two pro source redactions remain visible as “(redacted in source)”; no missing exercises were invented.

Foundation and Power map to stations; Engine to engine_builder; Complete to race_sim; Aerobic to recovery. Base maps to base, Pace to build, Accelerate and Prime to peak, Race to taper, matching the existing week configuration. Pro Week 4 Thursday is labeled Aerobic in the supplied source despite containing strength sets; that source label is preserved.

Two scoped deviations were necessary to satisfy populated-workout acceptance. The shared parser drops timed exercise lines such as “45 Minutes Easy Run”. New generators preserve lines when the unchanged parser returns null, including round/timing instructions. The beginner generator falls back to its original raw workout only when parsing produces an entirely empty main set. Against handoff baseline 59eae34, this changes only beginner w12-d4, from blank to “45 Minutes Easy Run”; the other 59 generated sessions and every byte of BEGINNER_PLAN_SESSIONS remain unchanged. makeSession, parseWorkoutLine and getPhaseInfo are unchanged.

The actual RaceCategory type is open/pro/doubles, not beginner. The hook accepts a string locally for robust persisted-category handling without changing the public type or adding an onboarding option.

Reproduction script (save as /tmp/hyrox-verify-plan.cjs and run from this worktree):

```javascript
const fs = require('node:fs');
const vm = require('node:vm');
const assert = require('node:assert/strict');
const { execFileSync } = require('node:child_process');
const ts = require(require.resolve('typescript', { paths: [process.cwd()] }));
function load(source, imports = {}) {
  const exports = {};
  vm.runInNewContext(ts.transpileModule(source, { compilerOptions: { module: ts.ModuleKind.CommonJS } }).outputText,
    { exports, require: name => imports[name] });
  return exports;
}
const dataText = fs.readFileSync('src/lib/hyrox-plan-data.ts', 'utf8');
const data = load(dataText);
const generators = load(fs.readFileSync('src/lib/mock-data.ts', 'utf8'), { './hyrox-plan-data': data });
for (const tier of ['OPEN', 'PRO']) {
  const source = fs.readFileSync('docs/hyrox-source/' + tier.toLowerCase() + '.md', 'utf8')
    .split(/^## Week /m).slice(1)
    .flatMap(week => week.split(/^### (?:Monday|Tuesday|Wednesday|Thursday|Friday) — Hyrox .+\n/m).slice(1));
  const raw = data[tier + '_PLAN_SESSIONS'];
  assert.equal(raw.length, 60);
  assert.equal(source.length, 60);
  raw.forEach((session, i) => {
    assert.equal(session.week, Math.floor(i / 5) + 1);
    assert.equal(session.day, i % 5 + 1);
    for (const field of ['workout', 'notes']) {
      let text = source[i].split(field === 'workout' ? '**Workout:**' : '**Notes:**')[1];
      if (field === 'workout') text = text.split('**Notes:**')[0];
      const lines = text.split('\n').filter(line => /^\s*- /.test(line))
        .map(line => line.replace(/^\s*- /, '').replaceAll('**', '').replace(/\[illegible.*\]/, '(redacted in source)'));
      assert.equal(JSON.stringify(session[field]), JSON.stringify(lines), tier + ' ' + i + ' ' + field);
    }
  });
  process.stdout.write(tier + ': 60 sessions, all source workout/note lines match, all week/day positions correct.\n');
}
for (const tier of ['Beginner', 'Open', 'Pro']) {
  const weeks = generators['generate' + tier + 'Plan']('2027-02-14');
  assert.equal(weeks.length, 12);
  const ids = new Set();
  for (const week of weeks) {
    assert.equal(week.sessions.length, 5);
    for (const session of week.sessions) {
      ids.add(session.id);
      assert.ok(session.title && session.coachNote && session.duration);
      for (const key of ['warmup', 'mainSet', 'cooldown']) assert.ok(session[key].exercises.length, tier + ' ' + session.id + ' ' + key);
    }
  }
  assert.equal(ids.size, 60);
  process.stdout.write(tier + ': all 60 detail pages have title, note, duration, warmup, main set and cooldown.\n');
}
const originalDataText = execFileSync('git', ['show', '59eae34:src/lib/hyrox-plan-data.ts'], { encoding: 'utf8' });
assert.ok(dataText.startsWith(originalDataText));
const originalGenerators = load(execFileSync('git', ['show', '59eae34:src/lib/mock-data.ts'], { encoding: 'utf8' }), { './hyrox-plan-data': load(originalDataText) });
const oldSessions = originalGenerators.generateBeginnerPlan('').flatMap(week => week.sessions);
const newSessions = generators.generateBeginnerPlan('').flatMap(week => week.sessions);
const differences = newSessions.filter((session, i) => JSON.stringify(session) !== JSON.stringify(oldSessions[i])).map(session => session.id);
assert.equal(JSON.stringify(differences), JSON.stringify(['w12-d4']));
assert.equal(newSessions.find(session => session.id === 'w12-d4').mainSet.exercises[0].exercise, '45 Minutes Easy Run');
process.stdout.write('BEGINNER: source data unchanged; 59 sessions identical; only w12-d4 empty main set repaired.\n');
let saved;
const hook = load(fs.readFileSync('src/hooks/use-plan-generator.ts', 'utf8'), {
  react: { useCallback: callback => callback },
  '@/stores/plan-store': { usePlanStore: () => ({ setPlan: plan => { saved = plan; } }) },
  '@/lib/mock-data': generators,
});
for (const category of ['open', 'pro', 'beginner', 'doubles', 'unknown']) {
  const plan = hook.usePlanGenerator().generatePlan({ category, raceDate: '2027-02-14' });
  assert.equal(plan, saved);
  assert.equal(plan.weeks[0].sessions[0].title, category === 'open' ? 'Open Foundation' : category === 'pro' ? 'Pro Foundation' : 'Foundation AMRAP');
  process.stdout.write('CATEGORY ' + category + ': correct plan selected and passed to store.\n');
}
```
