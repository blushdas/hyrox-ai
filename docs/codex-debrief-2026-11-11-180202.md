## Original Goal

A user who finished or skipped onboarding must never be sent back to onboarding, on any device, after sign-out, or after clearing storage. New users get a Skip control, and the race date uses a proper in-app date picker. The account-sync layer already exists on this branch (rebased on current main, force-pushed): extend it rather than rebuilding it.

## What Was Implemented

Round 3 addresses all eleven requested corrections. Onboarding redirects and fetch-error rendering no longer depend on local plan presence. Account fetch 401 clears account data and sends the user to sign-in; other fetch errors offer Try again. Completion is no longer persisted, legacy persisted flags are ignored, and signed-out/native paths clear it. Normal completion now derives its flag from the profile API response; Skip sets completion only after the account confirms a timestamp.

Backfill handles profile and plan separately: existing account entities win, only missing owned entities upload, concurrent hydration shares the upload, successful retries do not repeat, and failures log a redacted error and retain the local plan. A failed attempt is evicted from the session cache so the next load retries the missing entity. Normal profile-save/plan-failure also retains ownership for recovery.

First-time completion and backfill send conditional plan requests. Within the existing transactional batch, conditional saves do not archive an existing active plan and insert only if none exists. Concurrent first completions return the same active plan rather than creating a second archived history row. Existing profile timestamp COALESCE preserves first completion. Explicit redo/regeneration continues using the normal replacement path.

The shared calendar is modal, traps Tab in both directions, explicitly makes background branches inert, restores prior inert states on cleanup, and returns focus after Escape. Boundary tests pin local early/late clocks and a New York DST transition. The client catch uses the account layer's existing redacted console.error logging convention; no separate logger module exists in this repo.
