## Original Goal

Make the FINISHER web app installable to a phone home screen and prompt users to install it. Add a web app manifest and icons, then show a dismissible "Install FINISHER" banner on the dashboard. On Android/Chromium the banner triggers the native install prompt; on iOS Safari (which has no install event) it shows manual "Add to Home Screen" steps. It must stay hidden once installed, dismissed, or inside the Capacitor native app.

## What Was Implemented

FINISHER now serves a static web app manifest and four green F icons. The root listener captures browser install events independently of dashboard navigation. The dashboard card offers the browser install prompt when available, or Share instructions on iOS Safari. Dismissal is saved per browser; installation, native app, and standalone states hide the card. Existing dashboard content and authentication remain in place.
