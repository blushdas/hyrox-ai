## Original Goal

Package the existing FINISHER app for iOS with Capacitor, an opt-in static build, and a generated Xcode project. Preserve the existing web scripts and waitlist API. Attempt native tooling, record actual results, and provide the remaining simulator commands.

## What Was Implemented

- Installed Capacitor core, CLI, and iOS; the lockfile resolves all three to 8.5.2. CLI is a dev dependency. No other direct dependencies added.
- Added `capacitor.config.ts`: `ai.hyrox.finisher`, `FINISHER`, `out`. No remote server URL or native plugins.
- Added `npm run build:ios`. It copies source/config/public files into a fresh OS temporary directory, excludes `src/app/api` from that copy, shares installed node_modules, and runs Next.js with `CAPACITOR_BUILD=1`. Only a successful export replaces `out`; the temporary directory is cleaned in `finally`. The live API/source and `.next` server build are never moved or overwritten. Webpack is used for the temporary project so dependencies outside its root resolve correctly. Node 22+ is required by Capacitor and the TypeScript script.
- Gated `output: "export"`, trailing slashes, and unoptimized images behind the iOS environment flag. Existing dev/build/start scripts remain unchanged.
- Moved the existing session client component byte-for-byte to `session-detail.tsx`. The server page wrapper exports `generateStaticParams`: the same 60 `w{week}-d{day}` IDs used by the current plan generator are derived from `BEGINNER_PLAN_SESSIONS`. Web returns an empty params list and still serves arbitrary session IDs on demand; its build now labels this route SSG rather than the original dynamic label. Session data and status remain client-store driven. No fixed dates or mock session contents were baked into the UI.
- Generated `ios/` using `npx cap add ios`. Capacitor 8 defaults to Swift Package Manager, so CocoaPods is unnecessary for this project. Added a small native router because Capacitor's stock router sends every extensionless path to the root index; Next's export needs each route's own `index.html`. Both SceneDelegate and the storyboard use `FinisherViewController`. Missing routes and path traversal return the exported 404 document; assets/RSC text files retain their paths.
- Synced 697 exported files into the native project and verified every file byte-for-byte, including all 60 session pages. Generated web assets, config, Pods, and build output stay ignored; the Xcode project, Swift files, storyboard, plist, and SPM package are tracked.

References used: [Next.js static export](https://nextjs.org/docs/app/guides/static-exports), [Capacitor environment requirements](https://capacitorjs.com/docs/getting-started/environment-setup). Native router behavior was also checked directly in the installed Capacitor Swift source.
