## Original Goal
Show a dedicated, branded loading screen after the last onboarding step, preserving plan generation, the existing 800 ms dashboard redirect, and earlier steps.

## What Was Implemented
Submitting Build My Plan replaces the onboarding form with a full-screen FINISHER loading screen. It uses the existing logo, background and primary theme colors, a rotating green indicator, and short status text. The existing loading state controls it; navigation unmounts it automatically. The form is absent during loading, so its controls cannot receive further clicks or keyboard input. Reduced-motion preferences disable rotation. No generation, validation, state persistence, or navigation code changed.
